# Egypt-in-a-Box 🇪🇬

An interactive Python project exploring Ancient Egyptian history, culture, pharaohs, and the pyramids.

## About the Project

Egypt-in-a-Box is a personal Python project designed to present information about Ancient Egypt through an interactive application.

The project explores topics related to:
- Ancient Egyptian civilization
- Pharaohs
- The Pyramids
- Egyptian history and culture

## Technologies

- Python
- CustomTkinter
- Darkdetect

## Purpose

This project was developed as a practical application of Python programming concepts and to gain experience in building interactive desktop applications.
